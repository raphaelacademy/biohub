# biohub

## Como contribuir com o projeto

Este repositório é o projeto oficial do **BioHub**. Aqui vai ficar tudo: frontend, backend e o que mais for necessário. Para manter tudo organizado com o grupo trabalhando junto, sigam estas regras:

### Antes de começar
- Instale o [GitHub Desktop](https://desktop.github.com/) para facilitar o uso do Git.
- Clone este repositório na sua máquina antes de mexer em qualquer arquivo.

### Fluxo de trabalho
1. **Nunca programe direto na branch `main`.** Ela é a versão sempre funcionando do projeto.
2. Antes de começar sua parte, crie uma branch nova com um nome que identifique o que você vai fazer.
   - Exemplo: `joao-menu`, `maria-cadastro`, `pedro-backend-login`.
3. Faça commits com mensagens curtas e claras descrevendo o que mudou.
   - Exemplo: `adiciona botão de login no menu`.
4. Quando terminar (ou quiser mostrar o progresso), envie sua branch (`push`) e abra um **Pull Request** pedindo pra juntar na `main`.
5. O Pull Request será revisado antes de ser aceito (`merge`), pra garantir que tudo funcione junto.

### Organização de pastas
- `frontend/` — tudo relacionado à parte visual (HTML, CSS, JS).
- `backend/` — tudo relacionado à parte de servidor/dados (quando entrar em uso).

### Dúvidas
Qualquer dúvida sobre Git, GitHub ou o fluxo de trabalho, chama no grupo antes de travar sozinho tentando resolver.
